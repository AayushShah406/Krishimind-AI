# 🌾 KrishiMind AI — Frontend

Modern, high-performance web interface for the KrishiMind Agricultural Decision Support System.

Built with **React 19**, **TypeScript**, **Vite 6**, and **Tailwind CSS 3**.

---

## 🛠️ Tech Stack & Libraries

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite 6 with HMR
- **Styling**: Tailwind CSS 3.4 with `@tailwindcss/typography`
- **Icons**: Lucide React
- **Animation**: Framer Motion
- **Charts & Telemetry**: Recharts
- **State & Data Fetching**: TanStack React Query + React Context API
- **Form Management**: React Hook Form + Zod validation
- **Internationalization**: `i18next` & `react-i18next` (English, हिन्दी, ગુજરાતી)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Setup
Configure your API URL in `.env`:
```env
VITE_API_URL=http://127.0.0.1:8080/api
```

### 3. Start Development Server
```bash
npm run dev
```
The application will be accessible at [http://localhost:5173](http://localhost:5173).

### 4. Build for Production
```bash
npm run build
```
